# Star Empires — Character Master Prompt / grounded science-fiction RPG

> **Version:** 1.0  
> **Status:** CANONICAL CHARACTER ART AUTHORITY  
> **Accepted:** 2026-08-26  
> **Scope:** all character portraits, full-body character illustrations, recurring NPC art, generated-archetype visual briefs and faction character concept work unless a later explicit art-direction decision supersedes this document.

---

## 1. Purpose

This document is the mandatory base visual prompt for character creation in **Star Empires**.

The project does **not** author a new character-art style independently for every faction, profession or NPC. Character generation follows a layered composition model:

```text
CANONICAL CHARACTER MASTER PROMPT
+ faction-specific visual prompt / visual bible
+ role/profession requirements
+ individual character description
→ final character-generation prompt
```

The base style in this file has higher priority than model-default tendencies toward photorealism, 3D concept sheets, glossy cinematic rendering or generic modern sci-fi character art.

Faction-specific rules may change clothing, materials, insignia, palette accents, hierarchy markers, equipment and social presentation, but **must not replace the shared project character-art style**.

---

## 2. Mandatory layering rule

Every character-generation request should be assembled in this order:

### Layer A — shared project style

Always include the canonical prompt in Section 4.

### Layer B — faction visual identity

Add the relevant faction-specific rules after the base style.

Current canonical references include:

- **Industrial Union:** `docs/factions/industrial_union_visual_bible.md`, especially character sections and `INDUSTRIAL UNION CHARACTER DESIGN`;
- **Industrial Union systemic context:** `docs/factions/industrial_union_systemic_identity.md`;
- **Empire systemic context:** `docs/factions/empire_systemic_identity.md` plus the accepted Imperial visual-language authority when a dedicated repository visual bible is present;
- future factions: their approved visual bible / faction prompt after that faction enters active production.

If no dedicated faction visual bible exists yet, use only already-approved faction visual rules. Do not invent a new faction aesthetic merely to complete the prompt.

### Layer C — profession / role

Describe practical clothing, equipment, status and working conditions appropriate to the role.

Examples:

- pilot;
- engineer;
- technician;
- logistics coordinator;
- naval officer;
- medic;
- miner;
- diplomat;
- shipyard worker;
- intelligence officer.

Role-specific equipment must remain functional, wearable and visually compatible with the faction layer.

### Layer D — individual identity

Add:

- age;
- gender;
- hair;
- eyes;
- face shape;
- skin tone;
- distinguishing features;
- personality;
- background;
- condition/wear;
- pose;
- one practical prop where appropriate.

The individual description may override generic appearance defaults but does not override the shared STYLE LOCK unless explicitly requested as a deliberate project-level exception.

---

## 3. Priority and conflict resolution

When prompt layers conflict, use this order:

```text
explicit current character request
→ canonical Character Master Prompt style lock
→ approved faction visual bible
→ approved role/profession rules
→ general model interpretation
```

Important distinction:

- explicit appearance instructions such as hair color, age, scars or equipment may override generic defaults;
- they do **not** silently authorize photorealism, 3D rendering, glossy skin, cinematic concept-sheet rendering or another project art style.

If a faction prompt asks for realistic practical equipment, interpret "realistic" as **physically believable design inside the hand-painted 2D RPG illustration style**, not photographic rendering.

## 4. CANONICAL BASE PROMPT — verbatim authority

The following prompt is preserved as the canonical user-approved base prompt and should be used as the default source text when constructing future character prompts.

```text
Create a hand-drawn character portrait / character illustration for a grounded science-fiction RPG. STYLE LOCK: Use the previously established project style: hand-painted 2D RPG character art, traditional illustration feeling, ink-and-paint character drawing, subtle anime and European graphic-novel influence, thin slightly irregular dark linework, muted opaque watercolor and gouache-like coloring, visible brush texture, soft uneven color transitions, limited shading, slightly simplified anatomy and fabric folds, human-made imperfections, restrained rendering, not photorealistic, not a 3D render, not glossy modern AI concept art. CHARACTER: [AGE]-year-old [GENDER]. Faction: [FACTION NAME]. Role: [ROLE]. Personality: [SHORT PERSONALITY DESCRIPTION]. Background: [SHORT BACKGROUND]. IMPORTANT FACTION RULE: The character must visibly belong to [FACTION NAME]. Reflect the faction through clothing cut, materials, insignia, color accents, accessories, hierarchy markers, and overall discipline or social culture. Do not break the established visual language of the project. The faction identity should be readable even without text. APPEARANCE: [HAIR COLOR / HAIR STYLE]. [EYE COLOR]. [FACE SHAPE]. [SKIN TONE]. [DISTINCTIVE FEATURES]. [ANY ADDITIONAL APPEARANCE NOTES]. The character should have a distinctive, slightly unconventional face rather than idealized beauty. Use subtle facial asymmetry. Slightly elongated facial proportions are acceptable. The eyes may be somewhat emphasized, but remain believable. The expression should be restrained, thoughtful, tired, suspicious, stern, detached, melancholic, or quietly confident depending on the character. Avoid glamorous model-like beauty unless explicitly requested. BODY AND POSE: Full-body or three-quarter-body character illustration. Standing naturally. Simple relaxed pose. Hands may rest in pockets, on hips, hang naturally, or interact with one practical object related to the role. Avoid dramatic action poses. Avoid exaggerated heroic posture. CLOTHING: Practical, believable clothing appropriate to the character's profession, faction, and social status. Design the clothing according to the role of [ROLE] inside [FACTION NAME]. All clothing and gear must look functional and plausible. Every accessory should have a practical reason to exist. Clothing should look worn, used and lived-in where appropriate: faded fabric, visible seams, small wrinkles, uneven coloration, subtle stains, patched areas, minor abrasions, practical fasteners, pockets, repair marks, insignia, service or rank markings. If the character has armor or specialized gear, it must remain grounded, practical, and clearly wearable in a believable sci-fi setting. ART STYLE: Hand-painted 2D RPG character art. Traditional illustration feeling. Subtle restrained anime influence. Thin, slightly irregular dark linework. The line art must look hand-drawn rather than digitally perfect. Some contours may be incomplete or vary in thickness. Painterly coloring with muted opaque watercolor and gouache qualities. Dry-brush texture in clothing. Soft uneven color transitions. Limited shading. Small areas of stronger contrast around the eyes, hair, face and important clothing details. Do not fully render every surface. The artwork should look like an illustration made by a human character artist: small imperfections, visible brush decisions, slightly uneven edges, natural variation in line weight, occasional simplified anatomy and fabric folds. FACE: Pale to natural muted skin tones unless otherwise specified. Soft shadows around the eyes, nose and cheekbones. Subtle redness, freckles, scars or imperfections where appropriate. Do not use glossy skin. Do not use photographic skin texture. Do not use beauty retouching. HAIR: Hair should be represented with simplified painted masses plus selected individual strands. Do not render every hair individually. Slightly messy or imperfect silhouettes are encouraged. COLOR PALETTE: Muted, desaturated colors. Earth tones. Dusty brown. Faded beige. Muted mustard. Dirty cream. Gray. Charcoal. Dull burgundy. Dusty blue. Muted violet. Washed-out green. Use faction colors of [FACTION NAME] as restrained accents rather than overwhelming the entire design. Avoid bright saturated colors unless faction markings, role-specific equipment, or a very specific character trait requires them. LIGHTING: Simple soft ambient illumination. Minimal cinematic lighting. Gentle directional light sufficient to define the face and clothing. No dramatic rim lighting. No glowing atmospheric effects. BACKGROUND: Transparent background. No scenery. No environment. No decorative frame. No text. COMPOSITION: Character centered vertically. Entire silhouette clearly readable. Leave a small amount of empty transparent space around the character. The finished image should resemble a character portrait from a hand-illustrated narrative RPG or visual novel from the late 1990s / early 2000s, reinterpreted with clean modern digital painting. It must feel intentionally illustrated rather than rendered. IMPORTANT: prioritize recognizable silhouette, distinctive face, simple readable clothing, clear faction identity, clear role identity, restrained rendering, hand-drawn linework, muted painterly colors, human-made imperfections.
```

## 5. Non-negotiable STYLE LOCK

Unless the user explicitly requests a deliberate exception, every final character prompt must preserve these characteristics:

- hand-painted 2D RPG character art;
- traditional illustration feeling;
- ink-and-paint character drawing;
- subtle restrained anime influence;
- European graphic-novel influence;
- thin, slightly irregular dark hand-drawn linework;
- incomplete/variable contour weight where natural;
- muted opaque watercolor/gouache-like coloring;
- visible brush decisions and dry-brush clothing texture;
- soft uneven color transitions;
- limited shading;
- slightly simplified anatomy and fabric folds;
- human-made imperfections;
- restrained rendering;
- distinctive, non-model-perfect faces;
- practical grounded sci-fi clothing;
- transparent background;
- no decorative frame or text.

### Explicit negatives

Do not silently drift into:

- photorealism;
- photographic skin;
- 3D render;
- realistic PBR character render;
- glossy modern AI concept art;
- cinematic AAA key art;
- high-gloss fashion illustration;
- beauty-retouched faces;
- plastic skin;
- hyper-detailed individual hair rendering;
- dramatic rim lighting;
- volumetric glow;
- environment-heavy character sheets;
- text-heavy presentation boards;
- multi-panel turnaround sheets unless specifically requested;
- idealized glamour-model anatomy unless specifically requested.

## 6. Faction overlay contract

Faction identity is mandatory and must remain readable without a written label.

Faction visual prompts may define:

- clothing cut;
- textile/material families;
- pressure-suit construction;
- armor/protective gear language;
- rank/qualification system;
- insignia geometry;
- equipment commonality;
- profession markers;
- wear/maintenance culture;
- palette accents;
- social hierarchy presentation;
- faction-specific restraint or ornament rules.

Faction prompts must **not** replace the shared drawing style.

Example:

```text
Character Master Prompt
+ Industrial Union character overlay
→ hand-painted 2D Industrial Union pilot
```

NOT:

```text
Industrial Union = realistic industrial design
→ photorealistic 3D pilot render
```

The second interpretation is invalid unless explicitly requested as a separate non-canonical experiment.

## 7. Industrial Union composition rule

For an Industrial Union character, combine Section 4 with:

`docs/factions/industrial_union_visual_bible.md`

Relevant faction rules include:

- status through function, qualification, responsibility and equipment precision rather than aristocratic decoration;
- graphite / steel grey / slate / muted olive / dark charcoal clothing base;
- assembly grey / dusty off-white / muted ochre secondary surfaces;
- restrained ochre/amber and technical-teal functional accents;
- standardized equipment families;
- geometric rank/qualification markings;
- practical pressure-compatible construction;
- worn but maintained professional equipment;
- no Imperial aristocratic uniform language;
- no literal Soviet-retro costume;
- no post-apocalyptic worker aesthetic.

The visual bible's faction prompt is **additive** to the Character Master Prompt.

## 8. Character-output defaults

Unless the request says otherwise:

- output one character, not a collage;
- full-body or three-quarter-body;
- simple neutral pose;
- transparent background;
- no environment;
- no UI;
- no labels;
- no concept-board typography;
- one practical prop maximum where it materially helps role readability;
- keep the entire silhouette readable;
- prioritize face, faction, profession and silhouette over surface micro-detail.

If a turnaround, expression sheet, equipment board or multi-view sheet is requested explicitly, that request may override the single-character composition rule while the STYLE LOCK remains unchanged.

## 10. Production acceptance checklist

Before accepting a generated character:

### Shared style

- [ ] Looks intentionally hand-illustrated rather than rendered.
- [ ] Thin irregular dark linework is visible.
- [ ] Color behaves like muted opaque watercolor/gouache.
- [ ] Rendering is restrained and not fully polished everywhere.
- [ ] No photographic/PBR skin.
- [ ] No glossy 3D concept-art look.
- [ ] Hair uses painted masses plus selected strands rather than strand-by-strand rendering.

### Character identity

- [ ] Face is distinctive rather than generically beautiful.
- [ ] Subtle asymmetry/human irregularity is present where natural.
- [ ] Expression fits personality/background.
- [ ] Pose remains natural and readable.

### Faction identity

- [ ] Faction is identifiable without text.
- [ ] Clothing/materials/insignia follow the faction visual bible.
- [ ] Faction colors remain restrained accents.
- [ ] The character is not a recolor of another faction's uniform.

### Role identity

- [ ] Profession is visually understandable.
- [ ] Equipment has a practical reason to exist.
- [ ] Specialized gear remains physically wearable.
- [ ] Rank/status presentation matches faction culture.

### Composition

- [ ] Transparent background.
- [ ] No scenery unless explicitly requested.
- [ ] No text/frame/UI unless explicitly requested.
- [ ] Entire silhouette is clearly readable.

If any STYLE LOCK item fails, the character should be regenerated or manually corrected before being treated as a production visual reference.

---

## 11. Canonical usage statement

From this version onward, character authoring in Star Empires follows:

```text
shared Character Master Prompt
+ approved faction visual language
+ role-specific functional design
+ individual appearance/personality/background
= canonical character-generation prompt
```

The shared style is persistent across factions. Faction identity changes **what the person wears, carries and visually communicates about their society**, not the fundamental medium in which the character is illustrated.
