accepted chain:

```text

+ closed Stage-20F operational specialization/ownership
+ accepted Stage-20J extraction/production/freight/buffer/shipyard cadence
```

report rather than being replaced by an informal seed label.

```text

REJECT_SEED
```

with committed bounded Stage-20D repair additions returns `DETERMINISTIC_REPAIR`. Any failed matrix
row returns `REJECT_SEED`; `EXPLICIT_SCENARIO_OVERRIDE` remains a separately named authored-scenario
