# Stage 9E verification notes

The current recovery scenario temporarily holds its pre-existing physical reserve carriers for 100 simulated seconds before ordinary TradeAI route selection. This is a diagnostic control used to distinguish pre-project cargo depletion in a remote system from a construction-routing defect.

The delay is not a final gameplay policy. Before Stage 9E is marked complete, the benchmark must either replace it with an explicit deterministic activation condition or justify the reserve timing as part of the scenario fixture. No resources may be added after the destructive shock.
