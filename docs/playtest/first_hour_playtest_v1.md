# Плейтест первого часа — v1

Решение 2026-10-19: новые функции 23B заморожены до плейтеста первого часа. Черновик танкеров воды (W2)
лежит в локальной ветке `stage23b-water-tankers-draft`, в PR не входит.

Цель — узнать не «работает ли», а **понятно ли, интересно ли и не слишком ли долго**. Ошибки тоже
записываем, но главное — где игрок скучает, теряется или бросает.

## Первый час — гипотеза

Что игрок должен успеть и почувствовать (реальное время, не игровое):

| Минуты | Игрок делает | Должен понять или почувствовать |
|---|---|---|
| 0–5 | Начинает новую игру, покупает стартовый корабль, видит брифинг и станции на продажу | Кто я, где я, что можно купить |
| 5–15 | Покупает шахтёра и карты ресурсов, летит к участку, добывает, продаёт | Первый заработок своими руками |
| 15–30 | Второй цикл добычи и продажи, заправка | Цикл стал быстрее и понятнее; ясна цель (станция) |
| 30–60 | Копит на станцию, видит прогресс | Есть к чему стремиться, ожидание не пустое |

Что известно заранее из сценарных тестов (seed 2):
- шахтёр и карты — минуты; заработок цены станции (200 000 кр.) — ~335 тыс. тактов ≈ 9,3 игровых часа;
- максимальное ускорение в интерфейсе — ×8 (клавиши 1–4), есть пропуск времени по минутам или до события;
- при ×8 без пропуска 9,3 игровых часа ≈ 70 минут реального времени. **Скорее всего, станцию в первый час
  не купить** — это проверяем.

## Подготовка

1. Запуск: `.\run-generated-world.bat 2` (seed 2 — тот же мир, что в сценариях).
2. Новая игра, без старых сохранений.
3. Таймер на телефоне; этот файл или листок для заметок.
4. **Не подсказывать себе по коду и документам** — играть только по тому, что показывает игра.

## Что записывать

По каждой вехе — одна строка:

| Веха | Реальное время | Игровое время | Где застрял / что непонятно | Скука 1–5 | Ускорение / пропуск? |
|---|---|---|---|---|---|
| Купил стартовый корабль | | | | | |
| Понял, что делать дальше | | | | | |
| Купил шахтёра | | | | | |
| Купил карты ресурсов | | | | | |
| Первая добыча | | | | | |
| Первая продажа | | | | | |
| Первая заправка | | | | | |
| Второй цикл завершён | | | | | |
| Понял цель (станция) | | | | | |
| Станция куплена (если успел) | | | | | |

И отдельно:
- каждый раз, когда ждал больше минуты без решения — что ждал и сколько;
- каждый раз, когда не понял надпись, число или кнопку — какую;
- момент, когда захотелось выйти (если был).

## Вопросы после сессии

1. На какой минуте впервые стало интересно? Было ли вообще?
2. Где было скучнее всего?
3. Что было непонятно дольше всего?
4. Хотелось ли продолжить после часа? Почему?
5. Какие числа на экране мешали, а какие помогали?
6. Что бы ты убрал или сделал автоматическим в первую очередь?

## Критерии (предварительные)

- первый заработок — не позже 15 минут;
- нет ожидания больше 2 минут без решения игрока;
- к 10-й минуте игрок может сказать, к чему стремится;
- после часа хочется продолжить.

## После плейтеста

Находки оформляются как `playtest`-задачи (по `AGENTS.md`). Решения по темпу, автоматизации и целям
принимаются по ним, до возвращения к блокам 4–5.
