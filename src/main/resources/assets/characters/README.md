# Character runtime assets

Core-faction character art is rendered on the generated-world Factions tab.

- `empire/character_roster.png`: Empire premium roster, 6 cells × 56×84.
- `industrial_union/character_roster.png`: Industrial Union premium roster, 6 cells × 56×84.

The semantic left-to-right roster mapping is documented in `docs/characters/core_faction_character_roster.md`.

These images are presentation resources only. Their absence must never alter authoritative simulation state.
